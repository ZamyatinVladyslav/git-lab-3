## 8. fork
origin — мій власний форк репозиторію, куди надсилаються зміни.
upstream — оригінальний репозиторій, із якого було створено форк.
git fetch upstream — отримання інформації про нові зміни в оригінальному репозиторії.
git push origin — надсилання моїх комітів до власного репозиторію.
Pull Request створюється з моєї гілки у форку до upstream/main.
